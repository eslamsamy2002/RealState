# الحمد للتسويق والاستثمار العقاري والقانوني — بورسعيد
## El-Hamd Real Estate & Legal Services — Port Said Edition

> **منصة تسويق عقاري واستثمار وخدمات قانونية متكاملة لمحافظة بورسعيد — نموذج أولي عالي الجاهزية (MVP Prototype)**  
> مبنية بتقنيات React + Vite + TypeScript + Tailwind CSS ومجهزة للنشر المباشر بنقرة واحدة على **Vercel** دون الحاجة لخادم أو قاعدة بيانات منفصلة.

---

## 🌟 نبذة عن المشروع | Overview

**الحمد للتسويق والاستثمار العقاري والقانوني (بورسعيد)** هي منصة عقارية وقانونية متخصصة في السوق العقاري لمحافظة بورسعيد ومدينة بورفؤاد. تم تصميم المنصة لربط المشترين والمستأجرين والمستثمرين والملاك في بيئة موثوقة وعصرية، وتتميز بالهوية البصرية الرسمية للعلامة التجارية (الشعار الدائري "الحمد" بألوان الكحلي والذهبي والمنارة)، ونظام جغرافي موحد لأحياء بورسعيد، ونظام تسجيل دخول تجريبي يفرق بين حساب المشرف (Admin) والمستخدم العادي، مع لوحة تحكم إدارية ومساحة لحساب المستخدم.

---

## 🔐 نظام تسجيل الدخول والصلاحيات | Authentication & Roles

المنصة مزودة بنظام تسجيل دخول وإدارة صلاحيات تجريبي مبني بالكامل على `localStorage` لتوفير تجربة واقعية دون الحاجة لخادم backend:

### 1. حساب المشرف (Administrator)
- **البريد الإلكتروني:** `admin@darestate.local`
- **كلمة المرور:** `Admin123!Temp`
- **الصلاحيات والميزات:**
  - الوصول الكامل لصفحة الإدارة `/admin`.
  - مراجعة العقارات المضافة من المستخدمين واعتمادها (لتظهر فوراً للزوار) أو رفضها مع توضيح السبب.
  - إضافة عقارات جديدة مباشرة باسم الإدارة.
  - إدارة وتعديل وحذف العقارات المنشورة.
  - استعراض وتحديث حالات طلبات المعاينة والاستفسارات.
  - استعراض طلبات الاستشارات القانونية وطلبات حصص الاستثمار.
  - إدارة وتعديل محتوى الخدمات القانونية.

### 2. حساب المستخدم العادي (Regular Users)
- **التسجيل والدخول:** يمكن لأي زائر إنشاء حساب جديد بالاسم والبريد وكلمة المرور، أو استخدام زر "ملء حساب تجريبي" في صفحة الدخول `/login`.
- **الصلاحيات والميزات:**
  - تصفح وبحث وتصفية كافة العقارات المعتمدة في أحياء بورسعيد.
  - إرسال عقارات جديدة للبيع أو الإيجار (تنتقل تلقائياً لحالة "قيد المراجعة").
  - إبداء الاهتمام وطلب المعاينة أو التواصل المباشر عبر واتساب والهاتف.
  - تقديم طلبات استشارات قانونية وطلبات حصص استثمارية.
  - متابعة حالة كافة طلباته وعقاراته المعروضة في صفحته الشخصية `/account`.
  - **حماية المسارات (Route Guards):** يُمنع المستخدم العادي من الدخول لصفحة المشرف `/admin`، ويتم تحويله تلقائياً لصفحته الشخصية مع رسالة تنبيه واضحة.

> [!WARNING]
> **تنويه الأمان والخصوصية (Prototype Disclaimer):**  
> نظام تسجيل الدخول والتفويض هذا مخصص للعرض التوضيحي (Demo/MVP) ويعتمد على `localStorage`. لا تقم بتخزين كلمات مرور حقيقية أو بيانات شخصية حساسة. عند النقل للإنتاج الفعلي، يجب استبدال هذا النظام بخادم مصادقة حقيقي (مثل Supabase أو Firebase أو NextAuth/JWT).

## 📍 النظام الجغرافي لأحياء بورسعيد | Port Said Districts

تم توحيد النطاق الجغرافي للمنصة ليغطي كافة أحياء ومناطق محافظة بورسعيد الرسمية:
1. **حي الشرق (El Shark):** عقارات راقية، إطلالات على المجرى الملاحي لقناة السويس، وطرح البحر، وشارع الجمهورية وعاطف السادات.
2. **حي العرب (El Arab):** قلب المدينة التجاري النابض، أسواق تجارية ومحلات في شارع الثلاثيني والتجاريين.
3. **حي المناخ (El Manakh):** مواقع حيوية تجمع بين السكني والخدمي، مقرات شركات ومكاتب إدارية في شارع النصر وقرب الميناء.
4. **حي الضواحي (El Dawahy):** مناطق سكنية عائلية هادئة وقريبة من بوابات ومداخل المدينة.
5. **حي الزهور (El Zohour):** أكبر أحياء بورسعيد كثافة، شقق سكنية بأسعار ميسرة وفرص مناسبة للعائلات والشباب.
6. **حي الجنوب (El Ganoub):** مناطق الإسكان التعاوني الجديد والاستثماري، ومشروعات التنمية الواعدة.
7. **حي غرب (El Gharb):** المشروعات السكنية الحديثة، الديبة والقرى السياحية الساحلية غرب بورسعيد.
8. **مدينة بورفؤاد (Port Fouad):** الطابع الفرنسي الراقي، الفلل المستقلة، والمساحات الخضراء، والهدوء المطل على المجرى المائي.

> تم توحيد هذه الأحياء باللغة العربية عبر: شريط البحث السريع، فلاتر صفحة العقارات، نموذج إضافة العقار، بطاقات العرض، وصفحة تفاصيل العقار.

## 🚀 المميزات والصفحات الرئيسية | Core Pages & Features

### 1. 🏠 الصفحة الرئيسية (Home Page)
- شريط تنقل علوي فاخر يضم الشعار الرسمي (الحمد)، روابط الأقسام، زر اللغة، وزر الدخول/الحساب/الخروج.
- قسم **Hero** فخم يرحب بزوّار بورسعيد مع أداة بحث سريعة ثنائية المعاملة (بيع / إيجار) مفلترة حسب الحي ونوع العقار والسعر.
- شريط سريع لأحياء بورسعيد الثمانية للتصفية الفورية بنقرة واحدة.
- باقة مختارة من **العقارات المميزة في بورسعيد**.
- استعراض فكرة **حصص الاستثمار العقاري الجزئي** للمشروعات التجارية والمصرفية ببورسعيد.
- قسم **الحماية والخدمات القانونية العقارية** وفحص أوراق الملكية.
- تذييل كامل (Footer) بالشعار الرسمي وعنوان المقر الرئيسي بشارع الجمهورية وأرقام التواصل وشريط الأحياء وروابط سريعة.

### 2. 🏢 دليل وتصفح العقارات (Properties Catalog & Filters)
- استعراض العقارات ببيانات واقعية والأسعار بالجنيه المصري (EGP).
- تصفية متقدمة: حسب الحي (حي الشرق، العرب، المناخ، بورفؤاد، إلخ)، نوع العقار، الغرض (بيع / إيجار)، عدد الغرف، ونطاق السعر.
- خيارات ترتيب: الأحدث، السعر تصاعدي/تنازلي، المساحة.

### 3. 🔍 صفحة تفاصيل العقار (Property Details Page)
- معرض صور تفاعلي وشارات الحي والغرض.
- مواصفات تفصيلية: المساحة بالمتر المربع، الغرف، الحمامات، الدور، التشطيب.
- أزرار تفاعلية: طلب معاينة، محادثة واتساب فورية تحتوي كود العقار واسمه، واتصال هاتفي مباشر.
- صندوق إرشادات الأمان القانوني والتأكد من تراخيص الحي.

### 4. 📝 إضافة عقار جديد (Submit Property Page)
- نموذج سلس للملاك والمعلنين لإضافة عقاراتهم في بورسعيد واختيار الحي بدقة.
- **نظام المراجعة والاعتماد:** يُحفظ العقار مباشرة في `localStorage` بحالة **"قيد المراجعة" (Pending Approval)** ولا يظهر للزوار إلا بعد موافقة المشرف من لوحة الإدارة.

### 5. ⚖️ الخدمات القانونية العقارية (Legal Services Page)
- فحص سندات الملكية وتسلسل العقود.
- صياغة ومراجعة عقود البيع والإيجار الرسمية.
- استشارات الشهر العقاري والتسجيل والتصالح.
- نموذج حجز استشارة قانونية مخصص ومربوط بصفحة المستخدم ولوحة الإدارة.

### 6. 📈 حصص الاستثمار العقاري الجزئي (Investment Shares)
- نموذج تجريبي لفرص الاستثمار في أصول تجارية ومصرفية ببورسعيد بحصص استثمارية تبدأ من 50,000 ج.م.
- مؤشرات العائد المتوقع ودورية التوزيع، مع نافذة لحساب الاستثمار وإبداء الاهتمام.
- تنويه قانوني صارم يوضح الطبيعة التوضيحية للنموذج الأولي.

### 7. 👤 حساب المستخدم (User Account Page)
- مساحة مخصصة للمستخدم لمتابعة عقاراته المضافة (قيد المراجعة / معتمد / مرفوض)، وطلبات المعاينة، والاستشارات القانونية، وطلبات الاستثمار.

### 8. 🛡️ لوحة تحكم المشرف (Admin Portal - `/admin`)
- إحصائيات عامة فورية (عقارات معلقة، معتمدة، استفسارات جديدة).
- مراجعة العقارات المعلقة: زر **اعتماد ونشر** بنقرة واحدة، وزر **رفض** مع تسجيل السبب.
- إضافة وحذف وتعديل العقارات المباشرة وتعديل الخدمات القانونية ومتابعة طلبات العملاء.

## 💻 التقنيات المستخدمة | Tech Stack

- **React 18** مع **Vite** لأقصى سرعة أداء واستجابة.
- **TypeScript** لضمان دقة الأنواع وسلامة الكود.
- **Tailwind CSS** مع ألوان الهوية:
  - الكحلي العميق الفاخر (`#0B192C` و `#060E18`).
  - الذهبي الملكي (`#B89035` و `#D4AF37`).
  - الرملي الدافئ (`#FAF8F5` و `#ECE3D4`).
- **React Router DOM (v6)** مع حماية المسارات (Route Guards) وحل مشاكل التحديث عبر `vercel.json`.
- **Lucide React** للأيقونات العصرية.
- **Local Mock Data + LocalStorage Engine** للاحتفاظ ببيانات المستخدمين والعقارات والطلبات عبر التحديثات.

## 🛠️ التشغيل المحلي | Local Development

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20+ موصى به).
- مدير الحزم `npm`.

### خطوات التشغيل
1. افتح موجه الأوامر في مجلد المشروع:
   ```bash
   cd "d:\Abo elhamd"
   ```

2. ثبّت الحزم (في حال لم تكن مثبتة بالفعل):
   ```bash
   npm install
   ```

3. شغّل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```

4. افتح المتصفح على: `http://localhost:3000`

## 🚀 النشر على Vercel | Deploying to Vercel

المشروع مصمم ليعمل كـ Single Page Application (SPA) من خطوة واحدة دون أي خادم خلفي:

1. ارفع المشروع إلى حسابك على **GitHub** أو **GitLab**.
2. توجّه إلى [Vercel](https://vercel.com) واضغط **Add New Project**.
3. اختر المستودع الخاص بالمشروع، وستتعرف Vercel تلقائياً على إعدادات Vite:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. ملف `vercel.json` الموجود بالفعل في المشروع يتكفل بإعادة توجيه كافة المسارات إلى `index.html` لحل مشكلة 404 عند التحديث المباشر للمتصفح:
   ```json
   {
     "rewrites": [
       {
         "source": "/(.*)",
         "destination": "/index.html"
       }
     ]
   }
   ```
5. اضغط **Deploy** وستكون المنصة جاهزة وتعمل عالمياً في ثوانٍ معدودة مجاناً!
