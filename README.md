# دار إستيت — DarEstate Egypt (Real Estate MVP)

> **منصة تسويق عقاري واستثمار حديثة ومتكاملة في مصر — نموذج أولي عالي الجاهزية (MVP Prototype)**  
> مبنية بتقنيات React + Vite + TypeScript + Tailwind CSS ومجهزة للنشر المباشر بنقرة واحدة على **Vercel**.

---

## 🌟 نبذة عن المشروع | Overview

**دار إستيت (DarEstate)** هي منصة عقارية مصرية راقية مصممة لربط المشترين والمستأجرين والمستثمرين والملاك في بيئة موثوقة وعصرية. تركز المنصة على تقديم تجربة مستخدم استثنائية تشمل تصفح وتصفية الشقق والفلل والمحلات التجارية والمكاتب الإدارية، وإتاحة طلب خدمات استشارية وقانونية عقارية، ونموذج توضيحي مبتكر للاستثمار العقاري الجزئي (Fractional Shares)، مع لوحة تحكم إدارية ومساحة لحساب المستخدم.

---

## 🚀 المميزات الرئيسية | Core Features

### 1. 🏠 الصفحة الرئيسية (Home Page)
- قسم **Hero** فخم بواجهات معمارية حقيقية، شعارات موثوقة، وأداة بحث سريعة ثنائية المعاملة (بيع / إيجار) مدمجة مع الفلاتر.
- تصنيفات عقارية تفاعلية سريعة (شقق، فلل، محلات تجارية، مكاتب إدارية، دوبلكس، شاليهات).
- باقة مختارة من **العقارات المميزة (Featured Properties)**.
- استعراض فكرة **حصص الاستثمار العقاري الجزئي (Investment Shares)** مع مؤشرات العوائد.
- قسم **الحماية والخدمات القانونية العقارية (Legal Due Diligence)**.
- قسم استقطاب الملاك والمطورين لإضافة عقاراتهم.
- تذييل كامل (Footer) ببيانات الاتصال المصرية وروابط سريعة وتنويهات قانونية واضحة.

### 2. 🏢 دليل وتصفح العقارات (Properties Catalog & Filters)
- استعراض بطاقات العقارات ببيانات مصرية واقعية (الأسعار بالجنيه المصري EGP، المساحات، الغرف، الحمامات، التشطيب).
- فلاتر تصفية متقدمة:
  - نوع المعاملة: الكل / للبيع / للإيجار.
  - الموقع: التجمع الخامس والقاهرة الجديدة، الشيخ زايد، 6 أكتوبر، مدينة نصر، المعادي، العاصمة الإدارية، الساحل الشمالي.
  - نوع العقار: شقة، فيلا، دوبلكس، محل تجاري، مكتب إداري، عيادة طبية، شاليه.
  - عدد غرف النوم: 1، 2، 3، 4، 5+.
  - نطاق الأسعار: أدنى وأقصى بالجنيه المصري.
  - بحث بالكلمات الدلالية.
- خيارات ترتيب ذكية: الأحدث أولاً، السعر (تصاعدي/تنازلي)، المساحة (الأكبر أولاً).
- حالة عدم العثور على نتائج مع زر إعادة ضبط الفلاتر بنقرة واحدة.

### 3. 🔍 صفحة تفاصيل العقار (Property Details Page)
- معرض صور تفاعلي (صورة رئيسية كبيرة + مصغرات قابلة للتبديل).
- شارة الغرض (بيع / إيجار)، شارة الحالة، وحساب تلقائي لمتوسط سعر المتر المربع.
- مصفوفة المواصفات: المساحة، غرف النوم، الحمامات، الدور، سنة البناء، نوع التشطيب.
- قائمة المرافق والتجهيزات (أمن، مصعد، حمام سباحة، تكييف، موقف سيارات، إلخ).
- صندوق إجراءات التواصل السريع:
  - زر **إبداء اهتمام / طلب معاينة** بنافذة منبثقة pre-filled.
  - زر **محادثة مباشرة عبر واتساب** برسالة جاهزة تحتوي كود وعنوان العقار.
  - زر **اتصال هاتفي مباشر** بالمعلن.
- صندوق نصائح الأمان القانوني من دار إستيت للتأكد من تسلسل الملكية وتراخيص البناء.
- عقارات مشابهة مقترحة في أسفل الصفحة.

### 4. 📝 إضافة عقار جديد (Submit Property Page & Pending Flow)
- نموذج متكامل لعرض العقار للبيع أو الإيجار:
  - عنوان الإعلان ووصفه.
  - نوع العقار ونوع المعاملة.
  - السعر بالجنيه المصري (EGP).
  - المدينة، المنطقة، والعنوان التفصيلي.
  - المساحة، عدد الغرف، عدد الحمامات، ونوع التشطيب.
  - بيانات التواصل مع المعلن (الاسم، الهاتف، البريد).
  - رابط صورة العقار (مع معرض لاختيار صور نموذجية بنقرة واحدة).
- **نظام اعتماد الإعلانات (Approval Flow):**
  - عند الإرسال، يُحفظ العقار تلقائياً في `localStorage` بحالة **"قيد المراجعة" (Pending Approval)**.
  - يظهر تنويه رسمي واضح للمستخدم بأن الإعلان لن يظهر للعامة إلا بعد اعتماده من الإدارة.
  - شاشة تأكيد فورية مع رابط لمتابعة حالة العقار في حساب المستخدم، ورابط سريع للمعاينة من لوحة الإدارة.

### 5. ⚖️ صفحة الخدمات القانونية (Legal Services Page)
- خدمات عقارية متخصصة في السوق المصري:
  1. فحص سند الملكية والتسلسل القانوني.
  2. صياغة ومراجعة عقود البيع والإيجار.
  3. إجراءات التسجيل بالشهر العقاري ونقل التكليف.
  4. استشارات التصالح وتراخيص البناء وقانون 187 لسنة 2023.
- نموذج حجز استشارة قانونية مخصص يتيح اختيار الخدمة، وموقع العقار، وتفاصيل الاحتياج، والموعد المفضل للتواصل.
- تنويه قانوني صريح يوضح أن الخدمات إرشادية وتوضيحية للنموذج الأولي ولا تغني عن الاستشارة القضائية الرسمية.
- دعم تعديل وإضافة وإزالة الخدمات القانونية مباشرة من لوحة الإدارة.

### 6. 📈 حصص الاستثمار العقاري الجزئي (Real Estate Investment Shares)
- عرض تجريبي تفاعلي لفكرة الاستثمار في العقارات التجارية والإدارية بحصص مالية ميسرة تبدأ من 40,000 ج.م.
- بطاقات فرص استثمارية تشمل:
  - قيمة الأصل الإجمالية.
  - سعر الحصة وعدد الحصص المتاحة وإجمالي الحصص.
  - مؤشر نسبة التمويل المحجوز.
  - معدل العائد السنوي المتوقع (14% - 18.5%).
  - دورية توزيع العوائد (ربع سنوية / نصف سنوية).
  - بيانات المستأجر المؤسسي وعقود الإيجار.
- نافذة منبثقة تفاعلية لحساب قيمة الحصص المطلوبة تلقائياً وتسجيل إبداء الاهتمام.
- تنويه امتثال مشدد بعدم تحصيل أموال أو تقديم وعود استثمارية مضمونة.

### 7. 👤 حساب المستخدم (User Account Page)
- حساب تجريبي محفوظ محلياً (`localStorage`) مع إمكانية تعديل الاسم ورقم الهاتف والبريد.
- 4 أقسام تفاعلية:
  - **عقاراتي المعروضة:** لمتابعة العقارات المرسلة مع شارات الحالة (قيد المراجعة - معتمد - مرفوض مع إبداء السبب).
  - **استفسارات الشراء والإيجار:** سجل طلبات المعاينة مع تفاصيل العقار وتاريخ الطلب.
  - **الاستشارات القانونية:** متابعة طلبات التدقيق القانوني.
  - **طلبات حصص الاستثمار:** متابعة طلبات الحصص والقيم المحسوبة.
- خيار إعادة ضبط البيانات الافتراضية بنقرة واحدة.

### 8. 🛡️ لوحة تحكم المشرف (Admin Portal)
- بطاقات إحصائيات حية (KPIs): إجمالي العقارات، الطلبات المعلقة، العقارات المنشورة، إجمالي الاستفسارات، الاستشارات القانونية، طلبات الاستثمار.
- تبويب **مراجعة وتعديل العقارات (Moderation):**
  - تصفية حسب الحالة (الكل / معلق / معتمد / مرفوض).
  - زر **اعتماد ونشر للعامة** (يجعل العقار يظهر فوراً في الدليل العام للزوار).
  - زر **رفض العقار** مع كتابة سبب الرفض ليظهر للمعلن في حسابه.
  - إمكانية تعديل السعر والبيانات والمساحة أو حذف العقار.
- تبويب **إضافة عقار مباشر كإدارة:** لنشر عقار معتمد فوراً.
- تبويب متابعة وتحديث حالات استفسارات المشترين والمستأجرين (New / Contacted / Closed).
- تبويب متابعة وتحديث حالات الاستشارات القانونية.
- تبويب متابعة وتحديث حالات طلبات حصص الاستثمار.
- تبويب **إدارة محتوى الخدمات القانونية:** إضافة وتعديل وحذف الخدمات المعروضة على الموقع.
- زر استعادة البيانات الافتراضية التجريبية (Reset Demo Data).

### 9. 🌐 الدعم الثنائي للغات (Bilingual Arabic RTL / English LTR)
- الواجهة مصممة أصلاً باللغة العربية مع اتجاه **RTL** كامل.
- زر تبديل فوري في شريط التنقل للتحويل بين العربية والإنجليزية مع تعديل تلقائي للاتجاه `dir="ltr"` و `dir="rtl"` وترجمة كاملة لكافة النصوص والرسائل.

## 💻 التقنيات المستخدمة | Tech Stack

- **React 18** مع **Vite** لأداء فائق السرعة وبناء خفيف.
- **TypeScript** لضمان دقة الأنواع وسلامة الكود البرمجي.
- **Tailwind CSS** مع تخصيصات لونية راقية:
  - الكحلي العميق (Deep Navy: `#0B192C` و `#060E18`).
  - الذهبي الفاخر (Gold: `#B89035` و `#D4AF37`).
  - الرملي الدافئ (Sand / Warm Beige: `#FAF8F5` و `#ECE3D4`).
- **React Router DOM (v6)** للتنقل السلس ودعم الروابط المباشرة.
- **Lucide React** للأيقونات العصرية النظيفة.
- **Local Mock Data + LocalStorage Engine** للمحافظة على التعديلات والبيانات عبر التحديثات دون الحاجة لسيرفر أو قاعدة بيانات مدفوعة.

## 🛠️ التشغيل المحلي | Local Development

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو 20+ موصى به).
- مدير الحزم `npm`.

### خطوات التشغيل
1. افتح موجه الأوامر في مجلد المشروع:
   ```bash
   cd "d:\Abo elhamd"
   ```

2. ثبّت الحزم (في حال لم تكن مثبتة بالفعل):
   ```bash
   npm install
   ```

3. شغّل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```

4. افتح المتصفح على الرابط الموضح (افتراضياً: `http://localhost:3000`).

## 🚀 النشر على Vercel | Deploying to Vercel

المشروع مهيأ تماماً ليعمل كـ SPA على **Vercel** من خلال ملف `vercel.json` الموجود بالفعل في جذر المشروع:

```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```

### الطريقة الأولى: عبر لوحة تحكم Vercel (موصى بها)
1. ارفع المشروع إلى مستودع على **GitHub** أو **GitLab** أو **Bitbucket**.
2. سجل دخولك إلى [Vercel](https://vercel.com).
3. اضغط **Add New Project** واختر المستودع الخاص بك.
4. الإعدادات الافتراضية ستكون محددة تلقائياً:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. لا توجد أي متغيرات بيئة (Environment Variables) مطلوبة للتشغيل.
6. اضغط **Deploy**. في غضون ثوانٍ سيكون موقعك منشوراً ومتاحاً على نطاق عالمي سريع مجاناً!

### الطريقة الثانية: عبر Vercel CLI
```bash
npm i -g vercel
vercel
```
واتبع التعليمات على الشاشة.

هذا الموقع هو نموذج أولي وظيفي (MVP) مخصص للعرض التوضيحي واختبار تجربة المستخدم. يتم تخزين البيانات داخل المتصفح عبر `localStorage` ولا يتطلب خادماً خلفياً أو بطاقة دفع أو قاعدة بيانات. يمكن استبدال طبقة البيانات بسهولة بروابط REST أو GraphQL في المراحل اللاحقة.
