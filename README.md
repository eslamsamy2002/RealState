## El-Hamd Real Estate & Legal Services — Port Said Platform

منصة عقارية متكاملة واستشارات قانونية متخصصة لمحافظة بورسعيد ومدينة بورفؤاد، مبنية بأحدث تقنيات الويب السريعة (React 18 + Vite + TypeScript + Tailwind CSS) ومجهزة بالربط السحابي مع **Supabase** للتخزين الدائم للبيانات والصور، مع دعم النشر المباشر على **Vercel**.

## 🌟 نبذة عن المنصة | Platform Overview

**الحمد للتسويق والاستثمار العقاري والقانوني** هي منصة متخصصة للسوق العقاري في محافظة بورسعيد وبورفؤاد:
- **تصفح العقارات المعتمدة:** شقق، فلل، محلات تجارية، مكاتب إدارية، عيادات، وشاليهات للبيع والإيجار.
- **إضافة العقارات بدون تسجيل إجباري:** يمكن لأي مالك أو معلن إضافة عقاره مباشرة ورفع الصور دون اشتراط إنشاء حساب.
- **نظام الاعتماد والمراجعة الإدارية:** لا يُنشر أي عقار للجمهور إلا بعد قيام مدير المنصة بمراجعته واعتماده عبر لوحة الإدارة.
- **تخزين سحابي دائم للبيانات والصور:** ربط متكامل مع Supabase (PostgreSQL Database + Storage Buckets).
- **حسابات مستخدمين اختيارية:** إمكانية التسجيل والدخول لمن يرغب في متابعة طلباته، مع بقاء التسجيل اختيارياً.
- **لوحة تحكم المشرف (Admin Portal):** مسار محمي بصلاحيات حقيقية يظهر فقط للمشرف المصرح له.
- **الخدمات والاستشارات القانونية العقارية:** فحص سندات الملكية، صياغة العقود، وإجراءات الشهر العقاري ببورسعيد.
- **مفهوم الاستثمار العقاري المشترك:** دليل تعريفي واستشارات للمشاركة في الأصول التجارية المؤجرة مع إفصاح كامل للمخاطر.

## 🗄️ خدمة التخزين السحابي وقاعدة البيانات (Supabase)

تم اختيار منصة **Supabase** كأبسط وأوثق حل سحابي متكامل للمشروع للأسباب التالية:
1. توفير قاعدة بيانات PostgreSQL مدارة عبر الإنترنت دون حاجة لإدارة خوادم.
2. توفير حاوية تخزين سحابية للصور (`property-images`) مع روابط CDN دائمة وسريعة.
3. دعم سياسات الأمان المتقدمة على مستوى الصف (Row Level Security - RLS) التي تمنع المتصفح من استعراض العقارات غير المعتمدة أو تعديل بيانات الآخرين.
4. توفير نظام مصادقة (Auth) لإدارة حساب المشرف وحسابات المستخدمين بأمان.

### خطوات ربط Supabase في 3 خطوات بسيطة:

#### الخطوة 1: إنشاء مشروع مجاني على Supabase
1. ادخل إلى [supabase.com](https://supabase.com) وسجّل دخولك (أو أنشئ حساباً مجانياً).
2. اضغط على **"New project"**، واختر اسماً للمشروع (مثلاً: `elhamd-realestate`) وكلمة مرور لقاعدة البيانات، ثم اختر أقرب منطقة جغرافية.

#### الخطوة 2: تشغيل ملف المخطط والأمان بنقرة واحدة
1. افتح المشروع وتوجّه من القائمة الجانبية إلى **SQL Editor**.
2. افتح الملف `supabase-schema.sql` الموجود في مجلد المشروع، وانسخ كامل محتواه.
3. الصقه في محرر Supabase واضغط على زر **"Run"**.
4. سيتم فوراً إنشاء:
   - جدول العقارات `properties` مع سياسات حظر ظهور العقارات غير المعتمدة للعامة.
   - جداول الاستفسارات والطلبات القانونية وحصص الاستثمار.
   - حاوية تخزين الصور `property-images` مع تحديد الحد الأقصى 5 ميجابايت ودعم صور JPG/PNG/WEBP.

#### الخطوة 3: إدخال المفاتيح في ملف `.env`
1. من لوحة تحكم Supabase، ادخل على **Project Settings** -> **API**.
2. انسخ **Project URL** و **anon public key**.
3. في مجلد المشروع، أنشئ ملفاً باسم `.env` (أو انسخ من `.env.example`) وضع القيم كالتالي:
   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   VITE_ADMIN_EMAIL=admin@darestate.local
   ```
4. أعد تشغيل السيرفر المحلي أو ارفع التغييرات إلى Vercel. سيتصل الموقع تلقائياً بقاعدتك السحابية ويظهر مؤشر "🟢 متصل بقاعدة بيانات Supabase السحابية" في لوحة الإدارة.

## 🔐 نظام الصلاحيات ولوحة الإدارة (Admin Portal)

- **رابط لوحة الإدارة:** `/admin`
- **حماية الرابط:** المسار محمي بـ `ProtectedRoute`، ولا تظهر أيقونة ورابط "لوحة الإدارة" في شريط التنقل العلوي أو القائمة الجانبية إلا بعد تسجيل الدخول بحساب المشرف المعتمد.
- **حساب المشرف الافتراضي للاختبار:**
  - **البريد:** `admin@darestate.local`
  - **كلمة المرور:** `Admin123!Temp`
- **وظائف المشرف:**
  - استعراض العقارات الواردة بحالة "قيد المراجعة".
  - مراجعة الصور والمواصفات وبيانات المعلن.
  - بنقرة واحدة: **اعتماد ونشر** العقار ليظهر فوراً للزوار في صفحة العقارات، أو **رفض** العقار مع تسجيل سبب الرفض.
  - إمكانية إضافة عقارات جديدة مباشرة باسم إدارة المنصة (تُنشر فوراً).
  - تعديل وحذف العقارات ومتابعة استفسارات الزوار وطلبات الخدمات القانونية.

## 🚀 النشر على Vercel | Vercel Deployment

المشروع مهيأ بالكامل للنشر بنقرة واحدة على منصة Vercel:
1. اربط مستودع المشروع بحسابك على [Vercel](https://vercel.com).
2. في إعدادات **Environment Variables** على Vercel، أضف المتغيرات:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   - `VITE_ADMIN_EMAIL`
3. ملف `vercel.json` المضمن يتكفل تلقائياً بإعادة توجيه كافة المسارات (SPA Rewrites) لمنع حدوث خطأ 404 عند تحديث أي صفحة داخلية.
